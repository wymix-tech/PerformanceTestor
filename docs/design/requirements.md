# PerformanceTestor 需求文档

> 生成日期：2026-08-27　模块：全局　状态：已定稿
> 本文档固化产品全部功能需求（含三轮补充确认），作为后续设计与开发的基线。

## 1. 产品定位

面向 **Java 应用**的性能检测智能体平台：既能自动执行压测、采集 JVM / 调用链 / 慢 SQL 等检测数据，又能结合大模型分析性能问题根因、给出修复方案与修复提示词，并基于检测结果给出容量评估与扩容 / JVM 配置建议。

## 2. 功能需求

### 2.1 压测
- 自研 HTTP 并发压测引擎：并发数、持续时长、QPS 可配置；
- 统计 QPS、P50/P95/P99、错误率，输出压测报告；
- 预留 JMeter SPI 扩展点（同接口实现即可接入）。

### 2.2 JVM 监控
- JMX 采集：堆 / 非堆内存、GC、线程、CPU 等指标；
- Web 时序图表展示，支持应用切换与时间范围选择。

### 2.3 业务方法调用链耗时
- Java Agent 字节码增强自动埋点 Controller / Service / DAO 层方法；
- 记录每层耗时与链路耗时占比，生成调用树（嵌套表格）与火焰图。

### 2.4 慢 SQL 采集
- JDBC 执行拦截计时（Statement / PreparedStatement，与 ORM 无关）；
- MySQL 慢查询日志解析，双通道采集。

### 2.5 自动灌数据
- 按目标表结构（表名 / 字段 / 行数 / 生成规则）自动批量生成测试数据；
- 满足压测前置数据准备场景。

### 2.6 源码分析与修复闭环（补充需求 1）
- 源码采集：zip 上传 / Git 仓库克隆 / 本地目录路径 三种方式，防路径穿越与大小上限；
- 检测结果与源码关联定位（慢 SQL → Mapper/DAO，热点方法 → 类/方法，压测瓶颈 → Controller/Service）；
- 大模型根因分析：识别 N+1 查询、全表扫描、循环内查询、缺索引、锁竞争等代码问题；
- 多修改方案生成：每个问题 2-3 种方案，含涉及文件、修改点、代码改动要点、预期收益与风险；
- 修复提示词生成：用户选定方案后输出结构化修复提示词，供 AI 辅助编码工具（CodeBuddy/Copilot 等）直接使用。

### 2.7 分离部署与容量建议（补充需求 2）
- **分离部署**：平台与被测应用不在同一台服务器，避免压测与监控互相干扰；
- **容量评估**：基于压测并发-QPS-RT 曲线，插值计算目标 RT 阈值（如 P95<200ms）下可承受的最大并发 / QPS；
- **扩容建议**：规则引擎（CPU 使用率、RT P99、QPS 触顶、线程池饱和、Full GC 频繁、错误率超限等触发条件）+ 大模型解释，给出何时扩容、扩容方式（水平 / 垂直）、预估实例数；
- **JVM 配置建议**：基于堆使用曲线与 GC 频率，给出堆大小、GC 收集器（G1/ZGC）选择与关键参数（-Xmx/-Xms/-Xss/GC 参数）建议。

### 2.8 AI 对话（Function Calling）
- 自然语言指挥自动执行：执行压测 / 查询 JVM 指标 / 分析调用链 / 获取慢 SQL / 灌数据 / 分析代码问题 / 生成修复提示词 / 容量扩容建议 / 生成报告；
- 无 API Key 时降级为规则示例模式，保证可演示。

### 2.9 Web 可视化（7 屏）
1. 总览 Dashboard；
2. 项目管理（源码导入 / 分支同步 / 清理历史数据）；
3. 项目监控（JVM）；
4. 调用链分析（含慢 SQL Tab）；
5. 压测中心（含数据准备与容量建议 Tab）；
6. 性能优化（问题关联 / 多方案 / 修复提示词，含数据库连接配置）；
7. AI 助手。

## 3. 边界与非功能需求

- **存储**：优先 MySQL 单库（时序分区表），源码文件存磁盘；尽量降低第三方中间件依赖；
- **AI 依赖**：OpenAI 兼容大模型 API（baseUrl/apiKey/model 可配），无 Key 时可降级演示；
- **风险控制**：压测 / 灌数据 / 源码导入均做参数校验与上限保护；
- **可靠性**：agent 上报本地缓冲队列，失败指数退避重试、超时丢弃，网络抖动不影响被测应用；
- **文档**：全中文注释与文档，提供单机演示模式与多机生产模式的启动脚本与 README；
- **中间产出物**：全部归档至 `docs/` 目录并纳入 git 管理。

## 4. 关键约束

- 平台 → 被测：压测请求（80/443）、灌数据（数据库端口 3306 等）；
- 被测 → 平台：agent 上报端口（HTTP）；
- agent 上报地址配置为远程平台地址，支持网络断开场景。
