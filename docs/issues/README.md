# 性能问题分析归档

本目录归档 PerformanceTestor 的**性能问题分析结果与修复提示词**。

## 归档约定

- 每个问题归档文件对应一条 performance_issue 记录，包含：
  - 检测证据（慢 SQL / 热点方法 / 压测瓶颈 / JVM 告警）
  - 关联源码位置
  - 大模型根因分析
  - 2-3 种修改方案对比
  - 用户选定方案后生成的修复提示词（可复制给 AI 辅助编码工具）
- 命名建议：`issue-{id}-{issueType}-{yyyyMMdd-HHmm}.md`。
